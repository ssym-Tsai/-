# Changelog

## 0.1.0-preview.1 — 2026-10-21

Windows preview of **用默认浏览器打开chatGPT桌面端网页的插件**.

- Enable, inspect, and restore native web-link and localhost-link preferences.
- Preserve the initial preference backup and unrelated later configuration changes.
- Include Chinese and English instructions and a standalone skill package.
- Validate configuration behavior through five isolated integration tests.

This preview targets the desktop app's local Codex environment. Actual link clicks after a full app restart and other ChatGPT chat surfaces remain unverified. This release does not install a global click interceptor.
